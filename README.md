# STRA Consulting Services Website

Static website for STRA Consulting Services.

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with the real business email address.
3. Review all wording and any quantitative claims before publishing.
4. Upload the files to GitHub.
5. Deploy the repository using Vercel.

No paid hosting is required for the initial deployment.
